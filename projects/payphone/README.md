# PAYPHONE

## Public Project Overview

**Status:** Engineering development completed  
**Developed by:** Magen Daniel Systems LLP (MDS™)

PAYPHONE is a SIM-connected communication terminal developed for university and campus environments.

MDS completed the core product-engineering work, including:

- Product architecture and embedded-system integration
- Custom PCB design developed in-house by MDS
- Embedded firmware development
- SIM-based communication support
- Hardware and application-logic integration
- Prototype installation and functional testing

The project demonstrates MDS's ability to take a customer requirement through electronics design, firmware development, system integration and prototype validation.
